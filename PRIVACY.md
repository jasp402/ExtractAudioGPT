# Privacy Policy — ExtractAudioGPT

Last updated: October 10, 2026.

ExtractAudioGPT is a browser extension that lets users download audio generated by ChatGPT's Read Aloud feature.

## Data processed

The extension accesses audio responses associated with Read Aloud on chatgpt.com and chat.openai.com. This audio may contain personal information spoken in conversations. Captured audio is temporarily cached in the browser tab's memory to allow another download; the cache is cleared when the page is reloaded or closed. Downloaded files remain on the user's device until deleted.

## Use and sharing

Audio is processed locally to enable downloads and, when requested, conversion to MP3. Audio is not sent to the developer, developer-operated servers, or analytics providers. Chrome handles the file download. Data is not sold or used for advertising.

## Preferences

The extension uses `chrome.storage.sync` to save automatic-download and MP3-conversion preferences. Chrome may synchronize these settings through Google's services if browser synchronization is enabled.

## Permissions

- **downloads:** Save the requested audio file.
- **storage:** Remember user preferences.
- **Access to chatgpt.com and chat.openai.com:** Detect Read Aloud audio and add a download button.

## User control

Users can disable automatic downloads in the extension popup, delete downloaded files from their device, and uninstall the extension to stop its operation. The temporary audio cache is cleared when the page is reloaded.

## Contact

For privacy inquiries, open an issue at https://github.com/jasp402/ExtractAudioGPT/issues.

Use of information obtained through Google APIs will comply with the Chrome Web Store User Data Policy, including Limited Use requirements.
